# Regras de Codificação

Ao trabalhar em tarefas neste projeto, sempre siga as seguintes diretrizes:

1. **Sempre faça commit no código**: Commit o código iterativamente ao progredir nas tarefas.
2. **Arquivos pequenos**: Não crie arquivos com mais de 300 linhas. Caso precise, divida o arquivo em partes menores (refatoração).
3. **Sempre faça push para a main**: Ao terminar uma tarefa, o código finalizado deve ter feito push para a branch `main`.
4. **Modo Autônomo**: Execute as tarefas do início ao fim sem ficar fazendo perguntas ou pedindo permissão (a menos que seja absolutamente necessário). Assuma as decisões e siga em frente.
